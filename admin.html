🍔 Panel del local

Se configura una sola vez en este dispositivo. Los datos quedan guardados solo en este navegador.

Cómo sacar el token

  1. GitHub → tu foto → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → elegí el repo de la página
  4. Permissions → Contents: Read and write
  5. Generate, copiá el token y pegalo arriba

Visible apagado = el producto no se muestra en la página. Hay stock apagado = se muestra gris como agotado y no se puede pedir (las promos solo tienen "Visible"). Para una oferta, poné el precio nuevo en "Precio hoy" y el viejo en "Antes". Después tocá Publicar.
